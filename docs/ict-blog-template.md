# ICT 블로그 리포트 템플릿 (네이버, 매일 1회)

이 문서는 `scripts/live-trade-ict.js` / `docs/ict-strategy.md`가 만들어내는 데이터를 매일
네이버 블로그 글로 바꾸기 위한 템플릿·작성 규칙이다. 자동 발행 파이프라인(로컬 PC,
매일 오전 9시, 무인 발행)이 이 문서를 참고해서 글을 조립한다.

## 발행 규칙

- **주기/시각**: 매일 09:00 (Asia/Seoul)
- **검수**: 없음 — 완전 자동 발행 (사용자 승인 완료된 방식)
- **손익 공개 범위**: **%만 공개**. 실제 계좌 잔고($)·증거금 액수는 절대 넣지 않는다.
- **실행 위치**: 로컬 PC 전용. 네이버 로그인 세션이 로컬 크롬 프로필에만 있어서 클라우드
  에이전트로는 발행 불가 (`scripts/live-trade-ict.js`가 로컬 상시 프로세스인 것과 같은 이유).
- **목적**: 봇 실적 자랑이 아니라 **독자가 ICT 신호 읽는 법을 배워가는 콘텐츠**. 이겨도
  져도 같은 톤으로 정직하게 기록한다. 신호가 없는 날은 "신호 없음"을 그대로 쓴다 — 억지로
  내용을 만들지 않는다.

## 데이터 소스

| 데이터 | 출처 |
|---|---|
| 현재가/24h 변동/최근 7일 고저 | Binance klines API (`BTCUSDT`, 15m) |
| 최근 신호 목록·방향 표결(롱:숏, 최근 20개) | `scripts/lib/ict-signals.js`의 `detectICTSignals()`를 그대로 호출해서 재계산 (봇과 동일 로직) |
| 실거래 포지션/거래 기록 | `data/live-trades-ict.json` (`openPosition`, `trades`) — **pnlPct만 사용, balanceBefore/After의 $ 값은 쓰지 않음** |
| 진입 근거 스토리(스윕/MSS·BOS/FVG) | `data/trade-reports-ict.json`의 `reasonDetail` 또는 각 trade의 `mssType` |
| 차트 캡처 | 배포된 사이트의 ICT 탭 스크린샷 (스윕/MSS/FVG 마커 + "현재 셋팅" 패널 포함되게) |
| 봇 셋팅 고정값 | `scripts/live-trade-ict.js` 상단 상수 (`LEVERAGE`, `TRANCHES`, `TP1_R`, `TP2_R`, `STOP_R`, `DIRECTION_LOOKBACK`, `DIRECTION_MIN_EDGE`) — 값이 바뀌면 이 문서의 예시도 같이 갱신 |

## 섹션 구성 (고정 8단)

1. **오늘의 추세** — 현재 추종 방향(롱/숏/관망) + 판단 근거(최근 20개 신호 분포). 결과만이
   아니라 "왜 이렇게 판단했는지"를 반드시 설명한다.
2. **차트 캡처** — ICT 탭 스크린샷 삽입.
3. **오늘 자동매매 내역** — 지난 24h 신규 진입/청산이 있으면 스윕→MSS/BOS→FVG 순서로
   진입 스토리 서술 + 손익률(%). 없으면 "왜 관망했는지"(신호 동률/방향 불명확 등)를 정직하게
   설명한다.
4. **오늘의 ICT 개념 한 줄 강의** (로테이션, 아래 "개념 로테이션" 참고) — 거래가 없는 날에도
   콘텐츠가 마르지 않게 하는 고정 코너.
5. **누적 성과** — 총 거래수, 승률, 누적 수익률(%). 승패 관계없이 있는 그대로.
6. **셋팅 요약** — 진입/익절/손절 규칙, 레버리지, 봉 단위를 투명하게 공개.
7. **오늘의 한 줄 교훈** — 그날 상황에서 나온 리스크 관리/심리적 인사이트 한 줄.
8. **디스클레이머** — 아래 고정 문구 그대로 사용.

## 개념 로테이션 (④번 코너)

날짜 기준으로 순환해서 매일 다른 개념 하나씩 다룬다 (예: `(날짜 일련번호) % 6`):

0. 유동성 스윕 (Liquidity Sweep) — 스탑헌팅 개념
1. MSS / CHoCH — 구조 전환(추세 반전) 확인
2. BOS (Break of Structure) — 추세 지속 확인
3. FVG (Fair Value Gap) — 공정가치 갭, 되돌림 진입 자리
4. R배수 / 손절·목표가 — 승률보다 기대값이 중요한 이유
5. 방향 표결(다이렉션 리드) — 동률일 땐 관망하는 이유, 확신 없을 때 쉬는 것도 전략

그날 실제로 등장한 개념(예: 그날 진입 신호가 BOS였다면 ②번 대신 BOS를 다루는 식)과
겹치면 자연스럽게 그 개념으로 대체해도 된다 — 로테이션은 "마르지 않게 하는 기본값"이지
고정 규칙은 아니다.

## 톤 원칙

- 결과보다 과정(왜 이 신호에서 진입/관망했는지)을 보여준다.
- 이겨도 져도 같은 톤 — 잘된 날만 강조하면 광고글처럼 보여 신뢰가 깎인다.
- 특정 가격을 찍어 예측하지 않는다. "무엇을 관찰하면 방향이 정해지는지"(관찰 포인트)는
  설명하되 단정적 전망("오른다/내린다")은 쓰지 않는다.

# 비트코인 ICT 분석 — 지금은 롱도 숏도 아닌 '팽팽한 공방' 구간

## 지금 가격은?

비트코인은 현재 **$83,820** 부근에서 움직이고 있습니다(24시간 -0.32%). 지난 7일 동안은
$77,566 ~ $87,395 사이를 오가며 **위아래로 약 13%** 흔들렸습니다 — 뚜렷한 방향 없이
크게 출렁인 한 주였다는 뜻입니다.

## 최근 신호 흐름 — 롱에서 숏으로 무게중심이 옮겨가는 중

ICT 방식(유동성 스윕 → 구조 전환 MSS/BOS → FVG 진입)으로 최근 신호들을 순서대로
나열해보면:

| 시각 | 방향 | 유형 |
|---|---|---|
| 9/19 14:00 | LONG | BOS |
| 9/20 09:30~10:15 | LONG | MSS ×3 |
| 9/22 16:15 | LONG | BOS |
| 9/22 19:45 | SHORT | MSS |
| 9/23 20:15 | LONG | MSS |
| 9/24 09:30 | SHORT | BOS |
| 9/24 22:15 | SHORT | MSS |
| 9/25 02:45 | SHORT | MSS |

9/19~9/20엔 롱 신호가 연달아 나왔는데, 9/22 저녁 이후로는 **숏 신호가 더 잦아지는
흐름**이 보입니다. 다만 아직 저 9/19~9/20의 롱 뭉치가 최근 20개 신호 집계에 같이
들어가 있어서, 전체로 보면 **롱 10 : 숏 10 정확히 동률**입니다.

## 지금 판단: "방향이 없다"도 하나의 결론

저희가 쓰는 방식은 최근 신호 20개를 세서 **한쪽이 확실히(1개 초과) 앞서야만** 그
방향을 따라갑니다. 지금처럼 팽팽하면 롱 신호든 숏 신호든 뜨더라도 **진입하지 않고
관망**합니다.

이건 "모르겠다"는 회피가 아니라 규칙입니다 — 방향이 팽팽하게 갈릴 때 무리하게
포지션을 잡으면, 그 다음 캔들에 반대로 튀어서 손절만 반복하는 경우가 실제로 많았습니다.
**확신이 없는 구간에서 쉬는 것도 전략의 일부**입니다.

## 앞으로 뭘 보면 될까

특정 가격을 찍어서 예측하기보다, 이 구조에서는 **"신호 뭉치가 한쪽으로 확실히
쏠리는 순간"**을 지켜보는 게 핵심입니다.
- 지금부터 새로운 신호가 몇 개 더 뜰 때, **같은 방향이 연달아 나오는지** — 특히
  오래된 9/19~9/20 롱 신호들이 20개 집계에서 빠져나가면서 최근의 숏 쏠림이 그대로
  이어지면, 표결이 숏 쪽으로 넘어갈 가능성이 있습니다.
- 반대로 롱 신호가 다시 섞여 들어오면 계속 동률이 유지되며 관망이 이어질 수 있습니다.

즉 지금은 "다음 방향을 맞히는" 타이밍이 아니라 **"어느 쪽이 신호를 더 자주
만들어내는지 지켜보는" 타이밍**입니다.

## 최근 실전 매매 기록 (참고용)

같은 로직으로 실제 자동매매도 함께 돌리고 있는데, 최근 3건은 이랬습니다:

| 방향 | 결과 | 손익률 |
|---|---|---|
| LONG | 익절 | **+11.63%** |
| SHORT | 익절 | +0.13% |
| LONG | 손절 | **-2.34%** |

3건 중 2승 1패지만, 이긴 만큼 크게 벌고 진 만큼 적게 잃는 구조라 **누적으로는
+12.19%**입니다. 승률이 100%가 아니어도, 손절은 짧고 익절은 길게 가져가는 구조면
장기적으로 플러스가 될 수 있다는 걸 보여주는 사례입니다.

## 오늘의 ICT 한 줄 정리 — "동률일 땐 쉰다"

ICT 매매에서 가장 흔한 실수 중 하나가 **"신호가 떴으니까 일단 들어가고 본다"**입니다.
하지만 방향성 자체가 불분명한 구간에 진입하면, 이기든 지든 그 승부 자체가 운에
가까워집니다. 오늘처럼 롱/숏이 팽팽할 땐 **관망도 명백한 하나의 매매 결정**이라는 걸
기억할 필요가 있습니다.
