# 실거래 진입 조건 (Bitget 봇, 현재 코드 기준)

`scripts/lib/climax-signals.js`와 `scripts/live-trade.js` 코드를 그대로 정리한 문서입니다.
코드가 바뀌면 이 문서도 같이 업데이트해야 합니다.

전략은 PDF "찐바닥 잡는 법" **1장 — 마지막 봉이 가장 길 때(패닉 클라이맥스)** 입니다.
예전 쌍바닥 3분할 전략은 2년 백테스트(2024-10 ~ 2026-10)에서 거래당 계좌 약 -1%로
엣지가 없다고 확인되어 교체했습니다. 쌍바닥 감지 로직(`scripts/lib/signals.js`)은
대시보드 시그널 타임라인 표시용으로만 남아 있습니다.

## 공통 설정

| 항목 | 값 |
|---|---|
| 캔들 시간봉 | **15분봉** (Bitget 자체 데이터) |
| 방향 | **LONG만** (급등 클라이맥스 숏은 백테스트에서 손실이라 제외) |
| 레버리지 | **10x** |
| 최대 증거금 | 사용 가능 잔고의 95% (`BITGET_MARGIN_USDT`로 상한 지정 가능) |
| 비중 | 급락 폭에 따라 최대 증거금의 **1/3 · 2/3 · 전부** (아래 참조) |
| 청산 | 신호 봉 이후 **4번째 봉 마감 시 시장가** (= 1시간 보유) |
| 손절 | 신호 봉 종가 **-3%**, 거래소 프리셋 (봇이 꺼져 있어도 거래소가 실행) |
| 익절 | 없음 (시간 청산) |

## 진입 조건 — 마감된 15분봉 하나 기준, 전부(AND) 만족

1. **급락**: 종가가 직전 20봉(5시간)의 최고가보다 **3% 이상** 낮음
2. **거래량 폭발**: 거래량이 직전 20봉 평균의 **3배 이상**
3. **거래량 최대**: 거래량이 직전 20봉 중 어느 봉보다도 큼 ("월등히 많은 거래량")
4. **클러스터 첫 봉만**: 직전 7봉 안에 같은 조건을 만족한 봉이 있으면 건너뜀 —
   패닉 중에는 조건 봉이 연달아 나오는데, 그중 첫 봉만 진입

## 비중 (sizeTier)

| 급락 폭 | 비중 | 근거 (백테스트 1시간 뒤 평균 수익률) |
|---|---|---|
| 3% ~ 4% | 1/3 | 약 +0.3~0.5% |
| 4% ~ 5% | 2/3 | 약 +0.6~1.2% |
| 5% 이상 | 전부 | 약 +1.3~2% |

## 백테스트 요약 (Bitget 15m, 2년, 수수료 0.08% 포함)

- 61건, 거래당 평균 +0.27% (1배 기준), 표준편차 1.46%
- 위 비중 방식: 2년 2.38배 (1년차 1.27배 / 2년차 1.88배), 최대낙폭 36%, 최악 1회 -19.5%
- 신호가 드묾: 연 30건 정도, 조용한 장엔 몇 달 동안 없음 (예: 2025-07~09, 2026-03~05)
- 한계: 통계적으로 아직 약함 (t≈1.4). OKX 데이터로는 같은 규칙이 +0.13%/건으로 더 약함
- 교차 검증 (최근 2년, 2024-10 ~ 2026-09): 바이낸스 선물 데이터로도 1년차 +0.26% / 2년차 +0.22%
- 주의: 바이낸스 2020~2022년 데이터에서는 같은 규칙이 마이너스(-0.04% ~ -0.20%/건).
  2023년부터 플러스로 돌아섰으므로, 이 전략은 최근 시장 구조에 거는 것임

## OKX 봇 (`scripts/live-trade-okx.js`)

같은 규칙·비중·청산을 OKX 계좌에서 실행합니다. 다만 **신호는 Bitget 15분봉으로 잡습니다**.
OKX 자체 거래량으로 잡은 신호는 1년차 +0.11% / 2년차 +0.14%로 약했는데, Bitget 신호를
OKX 가격으로 매매하면 +0.39% / +0.26%였습니다 (차이는 OKX 거래량 데이터 쪽).

- 기록 파일: `data/live-trades-okx.json`, `data/trade-reports-okx.json`
  (예전 ICT 봇 기록 `data/live-trades-ict.json`은 그대로 보존)
- 실행: `run-live-trade-okx.bat`
- 두 봇이 보통 같은 봉에 같이 진입하므로 분산이 아니라 같은 베팅을 두 배로 하는 구조

ICT 봇(`scripts/live-trade-ict.js`)은 2026-10-30 중단했습니다. 2년 데이터에서 어떤 ICT 변형도
수수료를 넘지 못했습니다.

## 재시작

Node는 시작할 때 모듈을 메모리에 올려두므로, 코드가 바뀌면 `run-live-trade.bat`으로
재시작해야 적용됩니다. 시작 시 `reconcileOnStartup()`이 거래소 상태와 로컬 파일을
다시 맞추고, 예전 쌍바닥 전략으로 열린 포지션은 기존 방식(분할 익절/손절)대로 마무리됩니다.
