# 실거래 진입 조건 (현재 코드 기준)

`scripts/lib/signals.js`(및 동일 로직의 `app/components/BitcoinEntryChart.tsx`)와
`scripts/live-trade.js` 코드를 그대로 정리한 문서입니다. 코드가 바뀌면 이 문서도 같이
업데이트해야 합니다.

## 공통 설정

| 항목 | 값 |
|---|---|
| 캔들 시간봉 | **15분봉** (Bitget 자체 데이터) |
| 신호 최소 점수 | **85점 이상**만 실주문 |
| 레버리지 | **10x** |
| 증거금 | 매 거래마다 **그 시점 사용 가능 잔고의 95%** (고정 금액 아님) |
| 익절(TP) | 계좌 기준 **+8%** (= 가격 기준 +0.8%, 10x라서) |
| 손절(SL) | 계좌 기준 **-8%** (= 가격 기준 -0.8%) |
| 포지션 | 단일 포지션, LONG(매수)만 — 포지션 있으면 신규 진입 안 함 |
| TP/SL 실행 | 거래소(Bitget)가 주문에 프리셋으로 직접 관리 — 봇은 감지만 함 |

각 신호 후보는 15분봉 하나(`index`)마다 계산되고, 아래 순서대로 검사해서 **처음 맞는
조건 하나만** 채택합니다 (동시에 여러 개 해당해도 먼저 걸리는 것 하나만).

---

## 0순위: 진입 금지(`avoid`, WAIT) — 이게 걸리면 아래 패턴 다 무시

다음 중 하나라도 해당하면 그 캔들은 **매수 검토 자체를 안 함**:

- **첫 봉 지배**: 최근 4개 봉 중 첫 봉의 몸통이 평균의 1.7배 이상이고, 마지막 봉 몸통의
  1.25배 이상이며, 거래량도 평균의 1.3배 이상이면서 이후 3개 봉 중 최대 거래량인 경우
  **그리고** 4개 봉이 계속 하락(계단식 하락)일 때
- **재방문 구간 매도 과다**: 직전 저점(피벗) 2% 이내로 재방문 중인데, 최근 4개 봉이
  전부 음봉이고 거래량이 평균의 1.15배를 넘는 경우

---

## 패턴 1: `key-candle` (장대+거래량 컨펌 후보) — 3봉 구조

기준 캔들을 `현재봉`이라 할 때, `현재봉` 기준 2개 전(`장대봉`)부터 시작하는 3개 봉을 봅니다.

1. **장대봉** (`현재봉`의 2개 전)
   - 몸통이 최근 10봉 평균의 **1.5배 초과**
   - 거래량이 최근 10봉 평균의 **1.5배 초과**
   - 음봉 (종가 < 시가)
   - 최근 10봉 중 **최저가 갱신**(과매도)
2. **컨펌봉** (`현재봉`의 1개 전)
   - 몸통이 평균의 0.6배 이하 (도지) **또는**
   - 양봉이면서 몸통이 평균의 0.9배 이하 (작은 양봉)
3. **진입봉 = 현재봉** — 여기서 신호 발생
   - 아래꼬리 비율 ≥ 34% (`(min(시가,종가) - 저가) / (고가-저가) ≥ 0.34`)

**점수** = `78 + (장대봉 거래량 / 평균거래량) × 2 + (컨펌봉이 양봉이면 +5) + (지지선 근처면 +6)`,
78~96 사이로 제한.

---

## 패턴 2: `double-bottom` (쌍바닥 후보)

아래 조건을 **전부(AND)** 만족해야 함 — 하나라도 빠지면 진입 안 함:

- **기준 저점(previousPivot)**: 최근 3개의 "피벗 저점"(앞뒤 3봉보다 낮은 저가) 중
  **거래량이 가장 컸던 것**을 기준점으로 삼음 (단순히 가장 최근 피벗이 아님)
- 아래 중 하나:
  - 현재봉 저가가 기준 저점의 **0.7% 이내**로 재접근, 또는
  - 기준 저점을 살짝 깼지만(**1.2% 이내**) 큰 폭은 아님
- **재하락 거래량 억제**: 현재봉 거래량이 기준 저점 거래량의 1.15배 이하 **그리고**
  최근 평균 대비 1.6배 이하 (재하락 때 거래량이 과하면 탈락)
- **아래꼬리**: 비율 ≥ 34% (`(min(시가,종가) - 저가) / (고가-저가) ≥ 0.34`)
- **상승 RSI 다이버전스** (TradingView "RSI Divergence Indicator"와 동일한 정의): 현재봉
  저가가 기준 저점의 **+0.4% 이내**(같거나 더 낮은 저점)인데, 그 시점 **RSI(14)는 기준
  저점 캔들 때보다 더 높음** — 가격은 못 내려가는데 모멘텀은 이미 바닥을 찍고 반등하는
  전형적 강세 다이버전스. (이전에는 단순 가격 등락률(모멘텀) 비교로 근사했는데,
  실제 RSI 값끼리 비교하도록 교체함 — 아래꼬리와 OR가 아니라 **AND**로 둘 다 필요)
- **RSI(14) ≤ 40**: 재테스트 시점에도 여전히 과매도권이어야 함 (다이버전스 정의상
  기준 저점 RSI보다는 높지만, 그래도 40 이하는 유지해야 함 — 얕은 되돌림 걸러내기 위함)

**점수** = `66 + (다이버전스 조건 만족 시 +10) + (꼬리 조건 만족 시 +6) + (지지선 근처면 +5)`,
66~92 사이로 제한. 다이버전스와 꼬리 조건은 이제 진입 자체의 필수 조건이라, 패턴이
뜨는 순간 사실상 82점(지지선 근처 아님) 또는 87점(지지선 근처)만 나옴 — 실거래
최소 점수(85점) 통과하려면 **지지선 근처**여야 함.

## 참고: 지지선(supportNearby) 판정

최근 피벗 저점 5개 + 현재가 기준 반올림 라운드넘버(1000/500/100 단위, 가격대별로 다름)
3개를 지지선 후보로 삼고, 현재 저가가 그중 하나와 0.6% 이내면 "지지선 근처"로 판정.
